# Daily Standup Report Prompt

오늘의 팀 데일리 스탠드업 리포트를 작성해줘. 아래 형식에 맞춰 간결하게 정리해:

## 리포트 형식

### 어제 한 일
- 완료된 작업 목록을 bullet point로 정리

### 오늘 할 일
- 오늘 진행할 작업 목록을 bullet point로 정리

### 블로커
- 진행을 막는 이슈나 의존성이 있으면 명시
- 없으면 "없음" 으로 표기

## 작성 규칙

- 한국어로 작성
- 각 항목은 간결하게 한 줄로 정리
- 기술적 용어는 영어 그대로 사용 가능
- 마크다운 형식 사용
