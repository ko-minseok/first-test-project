# AI Daily Report Prompt

오늘의 AI/LLM/Agent 데일리 리포트를 작성해줘. web_search 또는 web_fetch를 사용해서 다음 주제들의 최신 뉴스(최근 24-48시간)를 검색하고 정리해:

## 수집 항목

1. **새로운 LLM 모델 출시** (GPT, Claude, Gemini, Llama, 오픈소스 모델 등)
2. **AI Agent 개발 동향** (AutoGPT, LangChain, CrewAI 등 에이전트 프레임워크)
3. **AI 서비스/제품 런칭** (새로운 AI 스타트업, 빅테크 AI 서비스)
4. **주요 AI 연구/논문** (arxiv 등에서 화제가 된 것)
5. **주요 LLM 모델 Deprecation/은퇴 일정** (OpenAI, Anthropic, Google 등의 모델 은퇴 예정 확인)

## 포맷 규칙
